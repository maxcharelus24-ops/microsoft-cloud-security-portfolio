
# Microsoft Cloud & Cybersecurity Portfolio

Welcome to my technical portfolio showcasing hands-on projects in Microsoft Azure, Microsoft Entra ID, Intune, Microsoft Sentinel, Microsoft Purview, Azure Virtual Desktop, and Microsoft 365 security.

These lab projects demonstrate my experience deploying cloud infrastructure, implementing enterprise identity and application security, automating identity lifecycle management, securing endpoints, monitoring threats, protecting sensitive information, and implementing cloud-based virtual desktop environments.

## Areas of Focus

- Identity & Access Management (Microsoft Entra ID)
- Conditional Access and Multi-Factor Authentication
- Enterprise Application Security and Role-Based Access Control
- OAuth 2.0 and OpenID Connect (OIDC)
- Workload Identity and Certificate-Based Authentication
- API-Driven SCIM Provisioning and Identity Lifecycle Management
- Customer Identity and Access Management (CIAM)
- Endpoint Security and Device Management (Microsoft Intune)
- Security Monitoring and Threat Detection (Microsoft Sentinel)
- Data Loss Prevention and Information Protection (Microsoft Purview)
- Microsoft 365 Security and Hardening
- Azure Virtual Desktop Deployment and Security
- Azure Infrastructure and FSLogix Profile Management

## Projects

### 1. [Microsoft Entra ID Security](Entra-ID-Security/README.md)
Implemented and documented identity security configurations, including Conditional Access, multi-factor authentication (MFA), and location-based access restrictions.

### 2. [Microsoft Intune Endpoint Security](Intune-Endpoint-Security/README.md)
Configured and documented Windows endpoint security policies covering device compliance, BitLocker encryption, and Microsoft Defender Antivirus.

### 3. [Microsoft Sentinel - Security Monitoring & Threat Detection](Microsoft-Sentinel/README.md)
Configured security analytics rules, investigated Microsoft Entra ID sign-in activity, and reviewed security incidents using Microsoft Sentinel and Azure Log Analytics.

### 4. [Microsoft Purview DLP – Confidential Data Protection](Microsoft-Purview-DLP/)
Implemented and validated Microsoft Purview Data Loss Prevention (DLP) controls using a custom sensitive information type, Exchange Online policy simulation, alert investigation, and enforcement testing to prevent unauthorized external sharing of confidential records.

### 5. [Azure Virtual Desktop - Deployment & Security Implementation](Azure-Virtual-Desktop/README.md)
Deployed and configured an Azure Virtual Desktop environment from scratch, integrating Microsoft Entra ID authentication, Azure RBAC, Azure Files, Microsoft Entra Kerberos, and FSLogix profile containers. Validated multi-user connectivity and persistent user profiles.

### 6. [Microsoft Entra Identity & Application Security](./Entra-Identity-Application-Security/)
Implemented and validated enterprise identity and application security controls using Microsoft Entra ID, including OpenID Connect authentication, application role-based access control, certificate-based Microsoft Graph authentication, API-driven SCIM provisioning, automated Joiner-Mover-Leaver lifecycle management, and Microsoft Entra External ID for customer identity and access management (CIAM).



All projects were performed in controlled lab environments. Documentation includes configuration evidence, screenshots, and validation notes where available.
